    WF
    □ □ Ein quantenmechanisches System wird durch eine C ∗ -Algebra A definiert.
    □ □ Es existiert F ∈ Herm(A) und ein Zustand ρ mit ρ(F 2 ) < [ρ(F )]2 .
    □ □ Für eine gegebene C ∗ -Algebra A und einen Zustand ρ gibt es einen Hilbertraum H,
        eine Darstellung π von A auf H und einen Vektor ξ ∈ H, so dass ρ(F ) = ⟨ξ, π(F )ξ⟩
        für alle F ∈ Herm(A).
    □ □ Die Lie-Algebra eines Teilchens in einer Dimension wird durch zwei Elemente, Q und
        P , erzeugt, die {Q, P } = 1, {Q, Q} = 0 und {P, P } = 0 erfüllen.
