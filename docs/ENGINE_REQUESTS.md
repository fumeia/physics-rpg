## 3. Three new encounter types (data is already in the room files)
Order inside each room: lessons, quiz, derive, calc, boss (theory before the fight). All strings are HTML with KaTeX.

### `lesson`: theory and intuition card (the "library terminal")
```
{ type: "lesson", id, title, tier: "theory" | "intuition", minutes, xp,
  source: [{file, where}],
  blocks: [ {kind: "text"|"intuition"|"pitfall"|"figure"|"exam", html} | {kind: "eq", tex, label?} ],
  check: [ {q, options[], correct, explain, source?} ] }
```
Render blocks top to bottom: `eq` as KaTeX display math with `label` as a caption; `intuition` (lightbulb),
`pitfall` (warning), `figure` (a figure described in words), `exam` (how the exam asks it) as styled call-outs.
`check` = 1-3 multiple-choice questions shown after reading; XP when all are answered correctly. Suggest: mark the lesson
"passed" when the checks are done (so later encounters can `requires` it), and add failed checks to spaced repetition.

### `quiz`: exam-style multiple choice ("quick fight")
```
{ type: "quiz", id, title, xp, passMark (fraction, e.g. 0.75), source: [{file, where}],
  questions: [ {q, options[], correct, explain, source?: {file, where}} ] }
```
Mirrors the 15 x 3-pt multiple-choice part of Refregier's exam. Show one question at a time, reveal `explain` after
each answer; pass if the fraction correct >= `passMark`. Wrong questions are good spaced-repetition candidates.

### `derive`: "show that" derivation practice (self-graded, step by step)
```
{ type: "derive", id, title, xp, source: {file, where}, goal, given: [html],
  steps: [ {prompt, reveal} ], keyPoints: [html] }
```
Show `goal` and `given`; for each step show the `prompt`, the player writes on paper, then clicks to `reveal`.
At the end show `keyPoints` and ask "did you get all of them?" (self-graded, like the boss key points).

### `codex.json` (optional, nice for an RPG "spellbook")
`{ course, entries: [ {id, group, title, tex, meaning, when?, source?} ] }`: every formula of the course, grouped.
Could be an in-game book/HUD panel; it is also exported as `notes/astrophysics/study/00-formula-codex.md`.
