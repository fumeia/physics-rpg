# Sirop project study material

Prep for the Sirop project "Fabrication of Liposomes for Microrobotic Drug Release Using Ultrasound"
(Razansky lab, UZH/ETH). This is separate from the exam game in `game/`.

- `study-guide.html`: one-page study guide (map, one-day plan, walkthroughs of the 4 papers,
  self-checks, lab-tour questions, 2-minute pitch, cheat sheet). It is published as a private claude.ai
  artifact. Open the file in any browser; equations need internet (MathJax from cdnjs).

Papers covered:
1. Kim, Wrede, ... Razansky, Sitti, Adv. Mater. 36, 2404514 (2024): acoustic trapping of flower-like microparticles in flow.
2. Purohit, ... Airan, Nat. Nanotechnol. 20, 1688 (2025): sucrose-core acoustically activatable liposomes.
3. Chen, ... Razansky, Chem. Soc. Rev. 53, 6068 (2024): multimodal optoacoustic imaging review.
4. Behzadi, ... Mahmoudi, Chem. Soc. Rev. 46, 4218 (2017): cellular uptake of nanoparticles.

The PDFs are not in the repo (copyright). Items marked "not in papers" or "my estimate" in the guide are
standard physics or inferences, not claims from the papers.

To remove: delete the `sirop/` folder. Nothing else in the repo depends on it.
